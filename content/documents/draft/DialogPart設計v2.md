
DialogPart - ログ型辞書を使ったパートチャットボットカーネルクラス
======================================


## 1. 会話ログの書式

```md
---
title: 日々の挨拶
scene: 室内
weather: 晴れ
datetime: 9/12 13:30
bot_expression: 平静 
author: skato
tags:
    {animal}: 犬,猫
---

# CUT 1
- user: こんにちは
- bot: [挨拶]こんにちは！
- user: いい天気だね！
- bot: {user}はどこか出かける？
- ゆう: テーマパークに行こう！

# CUT 2
datetime: 19:00
- user: こんばんは
- bot: こんばんは！
```

* ファイル先頭にはYAML Headerを書くことができ、titile, authorを記載できる。これらの情報は書誌情報でチャットボットの挙動に特に影響しない。
* headerにはscene, weather, datetime, bot_expression,tagsを記載でき、各特徴量のデフォルト値になる。
* 本文では地の文で以降の特徴量を上書きでき、リストの形式で会話のコーパスを記載する。

### 本文の書式
| 書式                               | 意味                                   |
|------------------------------------|----------------------------------------|
| `- user: <text>`                   | ユーザによる発話                       |
| `- bot: <text>`                    | チャットボットによる発話               |
| `- cue: <text>`                    | 環境などからの入力                     |
| `- <発話者名>: <text>`             | <発話者名>による発話                   |
| `# <コメント>`                     | 話題の切り替わり                       |
| `## <コメント>`                    | 話題の切り替わり                       |
| `datetime: <日付> <時刻>`          | 以降の日付時刻の設定                   |
| `date: <日付> <時刻>`              | 以降の日付時刻の設定                   |
| `time: <日付> <時刻>`              | 以降の日付時刻の設定                   |
| `scene: <シーン>`                  | 以降のシーンの設定                     |
| `weather: <天候>`                  | 以降の天候の設定                       |
| `bot_expression: <身振り>`         | 以降の身振りの設定                     |     


### 「text」の書式
ユーザやチャットボットの発言などをtextと呼ぶ。
* textの中で`{animal}`のように波括弧で囲った文字列はtagと呼び、出力時に別途定義した文字列に置き換えられる。
* textの中で`[笑い]`のように角括弧で囲った文字列はexpressionと呼び、話者のノンバーバルな表現を表す。出力文字列に含まれるexpressionはチャットボットのavatarとなり、text内のexpressionは空文字列に置き換える。expressionが指定されていない行ではheaderに記述されたbot_expressionがフォールバックとして使用される。
* textの中ではアスタリスク(*)とアンダースコア(_)を強調表示として扱う（markdown準拠）

## 3. 会話ログ利用した学習
会話ログの行には明示的に発話者、expression、テキストが示される他、日付、時刻、天候、場所などの特徴量も与えられる。

### 特徴量: 発話者
ログで示された発話者の情報は特徴量の一つである。他者の発言をチャットボットが聞いてログを検索する際の類似度スコアは以下の通り

| 発話者               | score |
|----------------------|-------|
| 現ユーザ名==発話者名 | +1.0  |
| user                 | +0.5  |
| cue                  | 0     |
| 現ユーザ名!=発話者名 | -0.5  |
| bot                  | -1.0  | 


### expression
ログの中で[]内にはノンバーバルな情報を書く。チャットボットの発言候補に含まれた場合それらはいずれかのexpressionに割り当てられ、それぞれに対応したavatarの表示に使う。

| expression  | 表記                   |
|-------------|------------------------|
| neutral     | [平常]                 |
| waving      | [手を振る] [手を振って] [挨拶して]  |
| smile       | [笑い] [笑み] [笑]     | 
| thinking    | [悩み] [顎に手をやり] [考え込み] |
| agree       | [同意]                 |
| cheerful    | [嬉しい] [ご機嫌で] [楽しげに] [楽しそうに] |
| surprise    | [びっくり] [驚いて]    |
| dissapoint  | [がっかりして] [肩を落として] [へこんで] |
| side-eyed   | [ジト目] [疑いの目で] |
| sad         | [悲] [悲しい]          |
| anger       | [怒] [怒り]            |
| sleepy      | [眠] [眠そう]          |
